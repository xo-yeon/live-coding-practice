# 문제 생성 프롬프트

오늘 날짜의 다음 순번으로 라이브 코딩 문제를 만들어줘. `AGENTS.md`를 따르고 최근 문제와 다른 주제를 선택해줘. Level 1과 2를 번갈아 사용하고, 실행 가능하지만 실무에서 급히 기능을 추가하며 생길 법한 핵심 문제 3~5개만 포함해줘. 공개 폴더에는 상황·요구사항·제한 시간, before/working 코드, 불완전한 공개 테스트만 두고 정답·문제 목록·채점 기준·reference solution은 대응하는 `.interviewer`에만 저장해줘. 생성 뒤 문제점은 말하지 말고 실행 명령만 안내해줘.
