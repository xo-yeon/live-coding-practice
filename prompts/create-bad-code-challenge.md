# 문제 생성 프롬프트

오늘 날짜의 다음 순번으로 라이브 코딩 문제를 만들어줘. `AGENTS.md`의 현재 학습 단계에 맞추고 최근 문제와 다른 주제를 선택해줘. 지금은 Level 1이며 한 파일에 핵심 문제 2개만 넣어줘. React/TypeScript의 짧고 실행 가능한 코드로 시작하고, 내가 원할 때만 파일 수와 난이도를 늘려줘. 공개 폴더에는 상황·요구사항·권장 시간, before/working 코드, 기본 공개 테스트를 두고 정답·문제 목록·채점 기준·reference solution은 대응하는 `.interviewer`에만 저장해줘. 생성 뒤 문제점은 말하지 말고 실행 명령만 안내해줘.
