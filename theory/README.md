# 코드를 읽고 고치는 이유: React·TypeScript 해설 교재

이 교재는 문제를 풀기 전에 **발견 단서 → 재현 → 원인 → 개선 코드 → 선택의 근거 → 검증**을 배우는 수업입니다. 정답과 해설을 처음부터 공개합니다. `practice` 및 비공개 면접 자료와 독립적으로 새로 만든 예제입니다.

Level은 이 저장소의 학습 단계이며 특정 회사의 공식 난이도나 기출 분류가 아닙니다. 아래 주제는 실무 코드를 이해하는 데 필요한 학습 범위입니다. 실제 출제를 보장하지 않습니다.

## 수업 방식

AI에게 “이론 01 수업 시작해줘”라고 말하면 교재를 바탕으로 예제와 해설을 먼저 설명합니다. 모르는 상태에서 답을 맞히도록 오래 기다리게 하지 않습니다. 설명이 끝난 뒤 전체 흐름을 본인 말로 정리하고, 그 내용에서 필요한 질문만 이어갑니다.

외울 내용은 코드 줄보다 **적용 조건과 보장해야 하는 동작**입니다. `useEffect`를 없애거나 `useMemo`를 넣는 행위 자체가 정답은 아닙니다. 반례와 한계까지 말할 수 있어야 다른 코드에 적용할 수 있습니다.

## 코드와 실행 범위

- 본문의 코드는 개념 설명용 발췌입니다. `Before`와 `After`는 대안이므로 같은 파일에 함께 붙이지 않습니다. 생략된 주변 환경은 각 수업에서 설명합니다.
- [examples](examples/)는 실제 실행 가능한 종합 예제와 테스트입니다. 정답이 공개된 학습용 코드이며 앱 화면에는 연결하지 않았습니다.
- 자동 테스트는 새 라이브러리 설치 없이 저장소 루트에서 아래 명령으로 실행합니다. 기존 연습 문제와 테스트 설정을 분리했습니다.

```bash
pnpm exec vitest run --config theory/vitest.config.ts
pnpm exec tsc -p theory/tsconfig.json
```

테스트가 통과한다는 것은 해당 시나리오가 검증됐다는 뜻입니다. 제품 전체의 완전성이나 실제 서버의 중복 처리까지 보장하지 않습니다.

## 복습 기록

```text
오늘 배운 유형:
문제가 의심되는 단서:
입력 → 사건 → 예상 결과:
원인:
해결 방법과 적용 조건:
다른 해결 방법과 선택 이유:
실패해야 하는 테스트:
이 해결법으로 보장하지 못하는 것:
```

Level 1은 값과 화면의 변화를 설명할 때, Level 2는 성공·실패·순서 변화의 결과를 설명할 때, Level 3는 수정 우선순위와 검증 범위를 근거와 함께 정할 때 학습 목표를 달성한 것입니다. 이후 별도 변형 문제로 넘어갑니다.
