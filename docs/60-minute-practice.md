# React/TypeScript 60분 연습

기존 01~03 워밍업 문제는 제거하고 60분 종합 과제에 집중합니다.
본 연습은 여러 파일을 가진 기능을 인수받고 데이터 흐름·상태·사용자 영향을 설명하며 수정하는 방식입니다.
실제 기업의 출제 형태를 단정하지 않으며, 지원 회사의 안내가 우선합니다.

첫 종합 과제는 `practice/2026-09-21/04-scheduled-transfers/problem.md`입니다.
컴포넌트, Hook, 타입, API, 스타일을 포함한 10개 작업 파일과 별도 목 서버·테스트가 있습니다.

코드를 1시간 전에 받는 상황을 연습하려면 60분 읽기 시간을 먼저 진행하고,
별도의 60분 타이머를 켜서 모의면접을 시작합니다.
읽기 시간에 수정하지 않고 메모만 남기면 실제 코딩 중의 판단과 구현을 구분해 평가하기 좋습니다.

새 Level 3 과제를 출제할 때는 다음을 기준으로 합니다.

- React와 TypeScript를 중심으로 8~12개 파일 정도의 하나의 사용자 기능을 완성합니다.
- 규모는 실무 데이터 흐름을 이해하는 데 필요한 정도로 제한하고 보일러플레이트로 늘리지 않습니다.
- 핀테크 관련 소재는 송금 예약, 거래 내역, 카드 한도, 정산 조회 등에서 선택합니다.
- 런타임은 정상 실행되며, 핵심 결함은 4~6개로 제한합니다.
- 폼, 상태 소유권, 서버 통신, 타입 경계, 테스트와 사용자 영향 설명을 함께 다룹니다.
- 공통 목 서버는 응답 지연과 실패를 재현하며 실제 계좌나 자금을 사용하지 않습니다.
- 문제 문서는 사용자 요구사항과 서버 계약을 공개하고 내부 결함 목록은 공개하지 않습니다.
- 지원자에게 60분 안에 전체 재설계를 요구하지 않습니다.
