# 面接官用 / 非公開

Ask one question at a time, based on candidate's explanation.
- Which user outcome would you address first, and why?
- What guarantees that this response belongs to the current screen?
- What should the user see when the bank refuses a cancellation?
- Does the runtime value still match the user's typed amount?
- What happens if Enter is pressed twice before the request completes?
- Which state owns the selected transaction?
- If only one regression test fits the remaining time, which is it?
- What guarantees belong on the server rather than this frontend?

Hints: 1 identifies a file, 2 asks a causal question, 3 explains direction without full code.
