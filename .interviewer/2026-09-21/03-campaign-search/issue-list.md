# 비공개 문제 목록

정답 공개 전에는 공개·요약·인용하지 않는다.

1. 이전 요청을 취소하거나 무시하지 않아 응답 순서가 바뀌면 오래된 결과가 최신 결과를 덮어쓴다.
2. Effect cleanup이 없어 언마운트 뒤에도 state 갱신이 이어진다.
3. HTTP 오류와 네트워크 예외를 처리하지 않아 사용자 피드백이 없고 unhandled rejection이 생길 수 있다.
4. 겹친 요청이 하나의 loading boolean을 공유해 먼저 끝난 요청이 로딩을 잘못 해제한다.
5. 모든 키 입력에 즉시 요청해 빠른 입력에서 불필요한 중복·중첩 요청이 발생한다.
