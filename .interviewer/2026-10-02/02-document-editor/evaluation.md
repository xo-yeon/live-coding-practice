# 비공개 채점 기준

기존 100점 배점: 발견 정확도 20, 우선순위와 근거 15, 동작과 버그 수정 25, 코드 품질 20, 테스트와 검증 10, 의사소통 10.

- 발견 정확도: 초안 소속, 실패 복구, 비동기 상태 소속을 요구사항과 연결하고 실제 결함으로 분류.
- 우선순위: 다른 문서에 잘못 저장할 위험, 입력 손실과 성공 오판, 복구 가능성 순으로 상황에 맞게 근거 제시.
- 수정: 전환 시 저장 내용으로 초안 초기화; 실패 시 오류와 초안 유지; 완료 시 현재 문서와 요청 문서 일치 여부 확인. 서버 계약 변경 불필요.
- 코드 품질: 독립된 초안 의도 보존, 불필요한 구조 개편 회피, 요청 중 중복 저장 방지 유지.
- 테스트: 실패 전 재현, 실패 후 재시도, A 저장 중 B로 전환을 비동기 대기와 격리로 검증.
- 의사소통: 사용자 영향·최소 변경 이유·실행한/못 한 검증을 분명히 설명.
