# 비공개 문제 목록

1. 문서를 선택할 때 `selectedId`만 바꾸고 `draft`를 바꾸지 않는다. 안내문에서 작성한 초안을 체크리스트에 저장할 수 있다. 데이터 소속이 섞이는 문제라 우선순위가 높다.
2. 저장 실패를 잡은 뒤 초안을 저장된 내용으로 되돌리고 성공으로 표시한다. 사용자 입력이 사라지고 저장 여부를 오판한다. 오류 표시·초안 유지·재시도가 필요하다.
3. 안내문 저장 중 체크리스트로 이동하면 안내문 요청의 성공이 현재 문서의 성공 표시로 나타난다. 비동기 완료 결과의 소속을 확인해야 한다.

시작 코드의 저장 버튼은 요청 중 비활성화되므로 중복 방지 자체는 장점이다. 특정 React 문법이나 state 개수만으로 문제로 보지 않는다. 공개 테스트는 정상 저장 한 번과 초기 화면만 확인한다.
