# 할부 예상 금액 조회

Level 2 입문 · 권장 30분 · 작업 파일 3개
처음에는 시간 제한 없이 진행해도 됩니다.

## 상황

카드 결제 전 할부 기간을 바꿔 예상 납부액을 확인하는 화면입니다. 모든 금액과 응답은 연습용입니다.

## 요구사항

- 고정 결제 금액은 120,000원이며 기간은 3·6·12개월입니다.
- 선택한 기간의 견적을 표시합니다. 조회 중에도 기간을 바꿀 수 있고 화면은 현재 선택을 기준으로 동작해야 합니다.
- 조회 중에는 로딩, 실패하면 오류, 성공하면 월 납부액과 총 납부액을 표시합니다. 이후 다른 기간을 선택하면 다시 조회할 수 있습니다.
- 서버 계약: 3개월은 900ms 후 총 123,000원, 6개월은 200ms 후 총 126,000원을 반환합니다. 12개월은 200ms 후 항상 실패합니다.
- 서버 계약과 지연 시간은 변경하지 않습니다. 캐시나 자동 재시도, 실제 결제는 범위 밖입니다.
- 외부 라이브러리 추가 없이 working에서 수정하고 필요한 테스트를 추가하세요.
