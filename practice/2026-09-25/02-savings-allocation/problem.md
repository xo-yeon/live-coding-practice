# 저축 목표별 금액 배분

Level 2 입문 · 권장 35~40분 · 작업 파일 3개
01 다음에 진행하며, 처음에는 시간 제한 없이 진행해도 됩니다.

## 상황

이번 달 저축할 금액을 여행·비상금·교육 목표에 나누는 미리보기입니다. 실제 이체는 없습니다.

## 요구사항

- 금액은 공백을 제외하고 숫자가 입력된 0~1,000,000원의 정수여야 합니다. 빈 값, 공백만 있는 값, 소수, 숫자가 아닌 값은 오류를 표시합니다.
- 각 목표의 비중은 1~100 정수입니다. 비중 합이 100일 필요는 없으며 각 비중 / 전체 비중 합으로 나눕니다.
- 원 단위로 각 배분액을 먼저 버리고, 남은 원은 화면의 목표 순서(여행 → 비상금 → 교육)에 따라 1원씩 나눕니다. 배분 합계는 입력 금액과 같아야 합니다.
- 미리보기 버튼을 누르면 결과를 표시합니다. 금액이나 비중을 편집하면 이전 결과와 오류는 지우고, 다시 버튼을 눌러 새 결과를 확인합니다.
- 잘못된 금액으로 미리보기를 요청하면 오류만 표시합니다. 0원은 정상 입력입니다.
- 목표 추가·삭제, 서버 저장, 실제 이체, 비중 입력 UX 개선은 범위 밖입니다. 비중은 제공된 UI로 1~100 정수만 사용합니다.
- 외부 라이브러리 추가 없이 working에서 수정하고 필요한 테스트를 추가하세요.
