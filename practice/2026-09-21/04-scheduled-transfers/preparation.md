# 사전 코드 읽기 60분

이 단계는 실제 60분 코딩 면접과 별도입니다.
실제 회사에서 사전 제공 코드 수정이나 AI 사용을 허용하는지는 별도로 확인하세요.
이 연습에서는 사전 시간에 실행·읽기·분석 기록만 하고 수정은 면접 시작 뒤에 합니다.

- 0~10분: 설치와 화면 실행, 정상 사용 흐름을 직접 조작합니다.
- 10~25분: 화면 진입점에서 컴포넌트·Hook·API·목 응답을 따라갑니다.
- 25~40분: 데이터 소유자, 상태 변화, TypeScript 타입과 실제 런타임 값의 경계를 설명해 봅니다.
- 40~50분: 관찰한 현상과 아직 검증하지 않은 가설을 나누고 사용자 영향으로 우선순위를 정합니다.
- 50~60분: 공개 테스트 실행, 추가할 테스트와 첫 수정의 범위를 정리합니다.

기록은 notes.md에 남깁니다. 정답 폴더는 열지 않습니다.
모든 파일을 암기하기보다 “어떤 사용자 행동이 어디의 상태와 서버 요청으로 연결되는지” 설명할 수 있게 준비하세요.
