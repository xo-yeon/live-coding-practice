# 분석 노트

## 확인한 문제

- **`status` 필터링 누락**: `status`가 `'COMPLETED'`가 아닌 거래(`'CANCELLED'`)도 건수와 금액 합계에 포함되는 문제.
- **입력 배열 변형 (Side Effect)**: `transactions.sort()` 사용으로 인해 호출 전후 입력 배열의 순서와 내용이 변형되는 문제.

## 우선순위와 근거

- **우선순위 1**: 불필요한 `sort` 동작을 제거하고 `filter`를 도입하여 요구사항인 `'COMPLETED'` 거래만 추출.
- **근거**: 요구사항에 "완료된 거래만 합산" 및 "입력 배열의 내용과 순서는 그대로 유지"가 명시되어 있어, 사이드 이펙트 제거와 정확한 수집이 최우선 수정 과제임.

## 검증 결과

- `working/summary.ts` 코드 수정: `sort` 제거 후 `filter((item) => item.status === 'COMPLETED')` 적용 완료.
- 공개 테스트 통과 및 추가 테스트 케이스 작성/검증 진행 중.
