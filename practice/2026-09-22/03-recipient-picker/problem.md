# 받는 분 선택

Level 1 · 권장 25분 (처음에는 시간 제한 없이 진행해도 됩니다.)

## 상황과 요구사항

이름을 검색하고 체크박스로 받는 분을 선택하거나 해제합니다. 화면의 체크 표시와 선택 인원은 즉시 일치해야 합니다. 검색어를 바꿔도 기존 선택을 유지합니다. ‘검색 결과 모두 선택’은 현재 보이는 사람을 기존 선택에 추가하며, 같은 사람을 중복으로 세지 않습니다. 검색 결과가 없을 때도 기존 선택을 유지합니다. 받는 분 목록의 id는 유일하고 연습 중 props는 변경되지 않는다고 가정합니다.

## 시작 방법

1. working/RecipientPicker.tsx 파일 하나만 읽습니다.
2. 입력과 기대 결과를 한 문장으로 적습니다.
3. 예를 하나 직접 실행하고 기대와 실제가 다른지 확인합니다.
4. 가장 중요한 문제 하나를 골라 이유를 설명하고 직접 수정합니다.
5. 공개 테스트에 요구사항을 확인하는 테스트 하나를 추가합니다.

```bash
pnpm vitest practice/2026-09-22/03-recipient-picker/tests
```

공개 테스트 2개는 시작 코드에서도 통과하는 기본 동작 확인용입니다. 모든 요구사항이 검증된 것은 아닙니다. 테스트를 추가하기 어렵다면 “테스트 작성법부터 알려줘”라고 요청하세요.

React 화면은 pnpm dev 실행 후 http://localhost:5173/practice/basics 에서 확인합니다. 01 함수 문제는 테스트로 실행합니다.

“03 문제 학습 모드로 시작해줘”라고 말하면 한 번에 질문 하나로 진행합니다. 코드를 대신 수정하거나 정답을 먼저 설명하지 않습니다. 필요할 때 힌트 1~3을 요청할 수 있습니다.
