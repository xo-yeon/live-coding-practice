# 분석 노트

## 확인한 문제

1. 체크 박스를 선택했을 때 해당 값이 화면에 바로 반영되지 않는다.
2. 검색 후 검색 결과 모두 선택을 클릭 했을 때 기존 클릭한 상태값이 유지되지 않고 검색 결과 내에 체크된 값만 반영한다.

## 우선순위와 근거

1. toggle 함수에서 상태가 변한 selectedIds값을 setSelectIds에 반영을 해도 즉시 화면에 반영되지 않은 이유는 useState함수가 얕은 비교를 하여 동일한 배열로 판단을 하기 때문이다.
2. 모두 선택 버튼 클릭 시 기존 선택한 selectedIds값이 무시된 채 새 값으로 업데이트 되고 있었다. (기존 선택된 값은 유지한 상태에서 검색 결과에 포함된 값만 추가되어야 한다.)

## 검증 결과

1. 체크박스 상태 변경 시 화면에 즉시 반영이 되고 있는지 확인한다.
2. 체크박스 상태 변경 후 이름 검색창에 다른 값을 넣고 모두 선택을 해도 기존 체크된 값은 유지되는지 확인한다.
