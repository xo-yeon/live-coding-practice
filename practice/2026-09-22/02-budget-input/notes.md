# 분석 노트

기본 사용 금액은 budget로 100000으로 설정되어 있음
input에 value(amount)값을 입력하면 실시간으로 remaining 값을 계산해서 화면에 표시되어야 함
amount가 100000이면 remaining을 0으로 표시

## 확인한 문제

1. budget에 대한 타입도 지정이 필요함
2. 정수 및 budget 값을 넘었을 때에 유효성 검사가 필요함

## 우선순위와 근거

데이터 규모가 크지 않은 코드였기 때문에 한번에 처리하기 보다 변수를 선언해 직관적으로 관리하는 방법을 선택함
